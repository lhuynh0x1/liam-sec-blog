Overview

The CySA+ (Cybersecurity Analyst+) is CompTIA's intermediate SOC analyst certification. It validates threat detection, analysis, and incident response skills — a natural follow-on to Security+.

Domain Breakdown

Security Operations (33%)

Heavy SIEM focus. Know your way around log analysis and alert triage:

  • SIEM tools: Splunk, Microsoft Sentinel, IBM QRadar
  • Log sources: Windows Event Logs, Syslog, NetFlow, DNS logs
  • Alert triage: true positive vs. false positive, severity tuning
  • Threat intel integration: STIX/TAXII, IOC feeds

Vulnerability Management (30%)

CVSS scoring (understand Base, Temporal, Environmental), remediation prioritization, scanning cadence.

CVSS Score Ranges:
  Critical  9.0–10.0  → Patch immediately
  High      7.0–8.9   → Patch within 30 days
  Medium    4.0–6.9   → Patch within 90 days
  Low       0.1–3.9   → Patch as resources allow

Incident Response (20%)

NIST IR lifecycle:

  1. Preparation
  2. Detection & Analysis
  3. Containment
  4. Eradication
  5. Recovery
  6. Post-Incident Activity (Lessons Learned)

Exam Tips

  • Many questions are scenario-based — think like a Tier 2 analyst
  • Know MITRE ATT&CK framework tactics and techniques
  • Understand the difference between threat hunting and incident response
  • CompTIA CertMaster Practice is worth every penny for this one
