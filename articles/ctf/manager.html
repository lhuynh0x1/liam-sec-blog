ADCS ESC7 Privilege Escalation

Enumerate certificates with Certipy:

certipy find -u raven@manager.htb -p 'R4v3nBe5tD3veloP3r!123' -dc-ip 10.10.11.236 -vulnerable

raven has Manage CA right on the CA — ESC7 condition. Steps:

  1. Grant yourself Manage Certificates right
  2. Enable the vulnerable SubCA template
  3. Request a certificate for Administrator (will fail, but saves the private key)
  4. Issue the pending certificate as CA manager
  5. Retrieve the issued cert
  6. Use certipy auth to get a TGT / NTLM hash for Administrator
certipy auth -pfx administrator.pfx -dc-ip 10.10.11.236

Pass-the-Hash or PTT → root shell.

Key Takeaways

  • Username-as-password spray is always worth running against MSSQL
  • xp_dirtree doesn't need sysadmin — it just needs the filesystem ACL
  • ADCS misconfigurations are extremely common in real-world AD environments; run Certipy on every engagement
  • ESC7 requires CA Manager rights — always enumerate CA ACLs, not just template ACLs
